# Deployment

This is a Next.js application. Set `NEXT_PUBLIC_SITE_URL` to the actual deployed origin and optionally set `NEXT_PUBLIC_API_URL` if using a compatible Fake Store API mirror. Install with `pnpm install --frozen-lockfile`, then run `pnpm build`. Verify API connectivity and all demo flows at the deployed origin. This repository has not been deployed as part of this work.
